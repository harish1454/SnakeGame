# 🎃 Snake Game - Halloween Edition 🦇

A spooky twist on the classic Snake game built with HTML5 Canvas, CSS, and JavaScript. Fully self-contained in a single HTML file with no external dependencies.

> *"Slither through the shadows and devour treats before the witching hour!"* 🕸️

## 🕷️ How to Play

1. Open `index.html` in any modern web browser.
2. Click **Start Game** or press any arrow key to begin your haunted journey.
3. Use the **arrow keys** to control the snake's direction:
   - ⬆️ Up Arrow: Slither up
   - ⬇️ Down Arrow: Slither down
   - ⬅️ Left Arrow: Slither left
   - ➡️ Right Arrow: Slither right
4. 🍬 Devour the treats to grow longer and increase your score.
5. 💀 Avoid crashing into the cursed walls or your own ghostly tail.
6. When the game ends, press **Enter** or click **Play Again** to rise from the grave!

## 👻 Features

- 🖼️ Smooth canvas-based rendering on a 20x20 haunted grid
- 🏆 Score tracking with on-screen cauldron counter
- 🌙 Eerie start screen with spooky instructions
- ☠️ Game over screen with final score and resurrection option
- ✨ Visual polish: gradient snake body, glowing food, subtle grid, and animated eyes
- 📦 No external dependencies required - it's frighteningly simple!

## 🔮 Technical Details

- Pure HTML5, CSS, and JavaScript - no tricks, just treats!
- Canvas size: 400x400 pixels (a perfect square of doom)
- Grid: 20x20 cells (20px per cell)
- Game speed: ~8 frames per second (fast enough to escape ghouls)
- Collision detection for walls and self-intersection
